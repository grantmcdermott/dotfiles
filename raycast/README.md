# Raycast

[Raycast](https://www.raycast.com/) is used for app launching and window
management. Configuration is stored in Raycast's internal database and can't
be managed via dotfiles. Back up and restore via
**Raycast Settings → Advanced → Export/Import**.

## Global Hotkey

| Key | Action |
|-----|--------|
| `Cmd+Space` | Open Raycast |

## Window Management

| Key | Action |
|-----|--------|
| `Alt+m` | Maximize |
| `Alt+c` | Center |
| `Alt+h` | Left half |
| `Alt+l` | Right half |
| `Alt+k` | Top half |
| `Alt+j` | Bottom half |
| `Alt+Shift+h` | Move left |
| `Cmd+d` | Next display |
